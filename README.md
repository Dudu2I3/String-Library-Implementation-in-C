# Библиотека для работы со строками на языке С

## Описание проекта

Реализована статическая библиотека для работы со строками, включающая пользовательские версии функций из стандартной библиотеки `string.h`, а также функции `sprintf` и `sscanf` с поддержкой форматирования.

---

## Основной функционал

### Реализация функций `string.h`
- Разработаны функции, аналогичные стандартной библиотеке `string.h`, с использованием префикса `s21_`.
- Функции работают с z-строками (однобайтовыми строками в кодировке ASCII).

### Реализация функции `sprintf`
- Поддерживаемые спецификаторы: `c`, `d`, `f`, `s`, `u`, `%`.
- Флаги: `-`, `+`, пробел.
- Ширина: (число).
- Точность: .(число).
- Длина: `h`, `l`.

### Реализация функции `sscanf`
- Полная поддержка форматирования с учетом флагов, ширины, модификаторов и типов преобразования.

### Обработка строк
- Дополнительные функции для работы со строками, аналогичные тем, что есть в классе `String`.
---

## Структура проекта

- Все исходные коды и заголовочные файлы находятся в директории `src`.
- Библиотека собирается в статический файл `libstring.a`.
- Тесты разработаны с использованием библиотеки `Check` для покрытия не менее 80% функций.

---

## Тестирование

- Подготовлены unit-тесты для всех реализованных функций.
- Для тестирования используются флаги `gcov`, чтобы создать отчет в формате HTML.
